

# Aplicación de Gestor de Tareas

Una aplicación web simple y ligera para gestionar tareas con operaciones CRUD (Crear, Leer, Actualizar, Eliminar), funcionalidad de búsqueda y cambio de tema. Desarrollada utilizando HTML, CSS y JavaScript
### Inspirado en*
 https://youtube.com/playlist?list=PLknwEmKsW8OuTqUDaFRBiAViDZ5uI3VcE&si=aKXquakxbC7vBTB5
 
## Características
- **➕ Agregar tareas**: Crea nuevas tareas fácilmente.
- **✏️ Editar tareas**
- *: Modifica los detalles de la tarea en cualquier momento.
- **🗑️ Eliminar tareas**: Elimina las tareas cuando estén completadas.
- **🔍 Buscar tareas**: Encuentra tareas por nombre o descripción.
- **🌙 Modo oscuro & 🌞 Modo claro**: Cambia entre temas para mayor comodidad

# 📐 Vista previa
*💭 Cómo funciona
Agregar tareas: Completa los detalles de la tarea y haz clic en Agregar para crearla.
Editar tareas: Haz clic en Editar junto a cualquier tarea para actualizarla.
Eliminar tareas: Haz clic en Eliminar para quitar una tarea de la lista.
Buscar tareas: Usa la barra de búsqueda para filtrar las tareas.
Cambiar temas: Alterna entre el modo claro y el modo oscuro para una mejor legibilidad.*

# 🏁 Cómo empezar

Para comenzar con la aplicación de Gestor de Tareas, sigue estos pasos:

1. **Clona el repositorio** en tu máquina local ejecutando el siguiente comando en tu terminal:
    ```bash
    https://github.com/abderrahmane-laourf/project-Task-Management-System.git
    ```


2. **Navega al directorio del proyecto**:
    ```bash
    project crud
    ```
    
3. **Abre el `index.html` archivo** en tu navegador, o usa una extensión Live Server para vista previa en tiempo real y desarrollo:
   - Si estás usando Visual Studio Code, puedes instalar la extensión Live Server y hacer clic en "Go Live" en la esquina inferior derecha para iniciar el servidor local.
   - Alternativamente, abre `index.html` directamente en tu navegador.

# ⛏️ Tecnologías utilizadas

Este proyecto está construido utilizando las siguientes tecnologías:

- **HTML**: Proporciona la estructura y el diseño básico de la aplicación.
- **CSS**: Se utiliza para dar estilo a la aplicación y habilitar el cambio de tema entre los modos claro y oscuro.
- **JavaScript**: Maneja la funcionalidad principal, incluidas las operaciones CRUD (Crear, Leer, Actualizar, Eliminar) y el interruptor de tema
